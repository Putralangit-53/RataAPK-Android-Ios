Bantuan & Alur Kerja

Kenapa kartu "Konversi" tidak langsung membuat APK?

RataAPK di HP ini adalah aplikasi WebView tunggal — untuk meng-compile APK/IPA baru dibutuhkan Android SDK, Gradle, dan (untuk iOS) Xcode yang berjalan di server, bukan di dalam HP. Karena itu proses compile sesungguhnya berjalan lewat GitHub Actions (workflow build-apps.yml), bukan di dalam aplikasi ini. Ketuk kartu di tab Konversi untuk menyiapkan & membagikan file project Anda — bukan untuk langsung menghasilkan APK di HP.

Alur lengkap dari HP sampai jadi APK

1. Pilih project di tab Konversi
File dipilih dari penyimpanan HP, lalu kotak "Bagikan" Android/iOS terbuka otomatis
2. Bagikan / unggah file itu
Kirim ke Admin lewat WhatsApp, atau simpan sendiri sebagai incoming/website.zip di root repo GitHub Anda
3. Jalankan workflow di GitHub
Tab Actions → "Build RataAPK (Android & iOS)" → Run workflow → isi nama app & package name
4. Unduh hasilnya
File .apk (Android) / .ipa atau build Simulator (iOS) muncul di halaman run tersebut, siap dipasang
